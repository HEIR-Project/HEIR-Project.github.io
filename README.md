# HEIR project website

English static research project page synchronized with the supplied HEIR arXiv manuscript on 2026-11-13. No build step or external runtime dependencies. Preview with `python3 -m http.server 8000`.

Figures are web-optimized exports of the manuscript source figures: teaser, collection protocol, dataset statistics, reconstruction validation, and execution pipeline. Original demo clips are retained. Interactive tables transcribe Gemma input/history, temporal planning, navigation, manipulation, initial planning, and additional Qwen/Muse/InternVL results. Table units and oracle input conditions follow the manuscript. Manipulation trials (60) and integrated episodes (27) use separate protocols.

Paper and Code remain disabled and labeled Coming soon, following the existing publication preference. The annotation dataset link remains available. Author names, order, affiliations and roles follow metadata.tex. This update does not claim arXiv acceptance or submission.
